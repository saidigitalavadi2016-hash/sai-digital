## Deploy on Vercel
1. Create a free account at https://vercel.com/
2. Install Git from https://git-scm.com/ (optional if using Vercel's dashboard upload/import workflow).
3. Put these files in a folder named `sai-digital`.
4. Push the folder to a GitHub repository.
5. In Vercel, click **Add New → Project**.
6. Import the GitHub repository.
7. Framework Preset: **Other** (or leave auto-detected).
8. Build Command: leave empty.
9. Output Directory: leave empty.
10. Click **Deploy**.
11. Vercel will provide a live URL such as `https://sai-digital-xxxx.vercel.app`.

## Custom domain
If you own `saidigital.in`:
1. Vercel → Project → Settings → Domains → Add Domain.
2. Enter `saidigital.in`.
3. Follow the DNS records Vercel displays at your domain registrar.
4. Wait for DNS/SSL activation.
5. Also add `www.saidigital.in` if desired.

## Deploy on Netlify
1. Create an account at https://www.netlify.com/
2. Open **Add new project → Deploy manually**.
3. Drag the `sai-digital` folder into the upload area.
4. Netlify gives you a live `*.netlify.app` URL.
5. Use Domain management to connect your own domain.
